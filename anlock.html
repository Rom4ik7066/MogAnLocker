MogLocker помогает увидеть отдельные системные признаки и предоставляет инструменты для ручных действий. Приложение не подменяет штатные средства защиты Windows.

✓Локальная утилита для Windows с открытым исходным кодом.
✓Изменения системных параметров выполняются только после явного подтверждения.
✓Исходники, инструкции и релизы доступны в репозитории проекта.
