# Luma Soundpad

Саундпад без сборки и внешних зависимостей. Интерфейс, код и логотип работают локально; сеть используется только браузером при первом получении приложения через сайт и при проверке обновления Service Worker.

## Архитектура

- `index.html`: стили, inline SVG, интерфейс и один классический скрипт с секциями `Store`, `AudioEngine`, `Input`, `UI`, `I18n`, `PWA`.
- `Store`: IndexedDB (метаданные и WAV/аудио Blob), схема 3, проверка данных; при отказе хранилища — временная память и экспорт для резервной копии.
- `AudioEngine`: Web Audio, лимитер, затухание голосов, ленивое декодирование, кэш с бюджетом 80 МБ на узком экране и 200 МБ на широком.
- `sw.js`: только HTTPS/HTTP, кэш приложения с версией и безопасным обновлением. `file://` работает без PWA и Service Worker.

## Дизайн-план

Цвета (HEX): графит `#171A1C` — основа; уголь `#202426` — поверхность; кость `#F0EEE8` — текст и светлая основа; лайм `#C8F169` — действие; янтарь `#F2AE5C` — один из 12 оттенков плиток; сталь `#727B80` — вторичный текст/границы. Цвет плитки выбирается из 12 близких по воспринимаемой яркости оттенков.

Шрифты: `ui-rounded`/системный округлый для марки и имён плиток, системный sans для остального. Размеры: 12, 14, 16, 20, 28, 40 px; обычные подписи не используют моноширинный шрифт. Отступы идут шагом 4/8 px, радиусы различаются у плиток, панели и небольших контролов.

Телефон:

```text
┌ марка ─ банк 1 ─ банк 2 ─ настройки ┐
│ плитка │ плитка │
│ плитка │ плитка │
│ плитка │ плитка │
├ Стоп ─── громкость ─ Правка ─ Добавить ┤
└ safe area ─────────────────────────────┘
```

Десктоп:

```text
┌ марка ─ банки ─ поиск ─ настройки ┐
├ Стоп всё ─ громкость ─ Правка ─ Добавить ┤
│ плитка │ плитка │ плитка │ плитка │
│ плитка │ плитка │ плитка │ плитка │
└ состояние ──────────────────────────┘
```

Принципы: физичные LED-клавиши — единственный выразительный акцент; плотная квадратная рабочая сетка без карточек вокруг; транспортные и настройки — сдержанные и быстро достижимые. Плитка меняется только как ответ на нажатие, играет с заметной подсветкой, без декоративного движения.

## Запуск и установка

- Локально: откройте `soundpad/index.html` двойным щелчком. IndexedDB/аудио поддержка зависит от браузера; установка и офлайн-кэш доступны только через HTTP(S).
- GitHub Pages: опубликуйте содержимое папки `soundpad/` как статический сайт. Все ссылки относительные, размещение в подпапке поддерживается.
- Netlify или Cloudflare Pages: перетащите папку `soundpad/` в интерфейс ручного деплоя.
- Android и Chromium на ПК: откройте сайт и выберите «Установить приложение»/«Установить».
- iPhone/iPad: Safari → «Поделиться» → «На экран Домой». Без установки Safari может удалить данные сайта после длительного периода неактивности (в частности, ориентируйтесь на ограничение около 7 дней).

## Звуки, банки и перенос

Звуки до 25 МБ и 3 минут можно добавить выбором нескольких файлов или перетаскиванием. При неподдерживаемом формате конвертируйте аудио в WAV, MP3 или M4A. Каждый файл проходит проверку отдельно, ошибка одного не мешает другим. Для обмена используйте экспорт `.luma`; импорт проверяет заголовок и записи, затем предлагает объединить доски или заменить текущую.

Правка: включите «Правка», затем нажмите плитку; на ПК также доступно контекстное меню правой кнопкой. Для переименования или удаления банка нажмите на вкладку правой кнопкой мыши. В редакторе назначьте клавишу через кнопку «Клавиша»: Escape отменяет, Backspace очищает. Горячие клавиши работают по `event.code`, пока вкладка активна; сочетания Ctrl/Alt/Meta исключены.

## Аудиомаршрутизация

Если браузер реализует `AudioContext.setSinkId`, выбор аудиовыхода появляется в настройках. Второй независимый выход браузер поддерживает не везде; при отсутствии API выбор скрыт.

- Windows: установите VB-CABLE. Оставьте основной выход Luma на наушниках, выберите `CABLE Input` во втором выходе, а в OBS/Discord/Zoom/игре с voice input выберите `CABLE Output` как микрофон.
- macOS: используйте BlackHole и настройте виртуальный вход как микрофон приложения для эфира.
- Linux: выберите виртуальный sink в PipeWire/PulseAudio, затем источник этого sink в программе записи.

При наличии `AudioContext.setSinkId` можно выбрать основной выход; если также есть `HTMLMediaElement.setSinkId` и `MediaStreamAudioDestinationNode`, доступен второй выход. Так можно оставить мониторинг в наушниках, а копию направить на виртуальный кабель. Браузер не может сам записывать звук в микрофон, вкладывать звук во все приложения или ловить клавиши, когда вкладка/окно свёрнуты или неактивны. В Discord и играх с настройкой voice input звук доступен после выбора виртуального кабеля как микрофона; игры без такого входа требуют отдельного нативного решения.

## Ручная проверка за 5 минут

- **ПК (2 минуты):** откройте сайт, запустите несколько плиток, проверьте «Стоп всё», назначьте клавишу, включите режим удержания и отпустите клавишу; добавьте WAV, перезагрузите страницу, экспортируйте и импортируйте доску.
- **Android (1,5 минуты):** установите PWA, сыграйте несколько плиток двумя пальцами, проверьте прокрутку без случайного срабатывания, добавьте аудио и включите виброотклик, если браузер его разрешает.
- **iPhone/iPad (1,5 минуты):** откройте в Safari, добавьте на экран «Домой», активируйте аудио жестом, проверьте тач, громкость, режим петли, импорт/экспорт через меню «Поделиться». Проверьте звук после возврата из звонка/переключения приложения.

## Ограничения и допущения

- Максимум файла — 25 МБ, длительность — 3 минуты; лимит одновременных голосов — 32.
- Внутренний формат доски — `LUMA1`, заголовок JSON и бинарные части. Импорт заменяет либо добавляет банки; существующие записи не перезаписываются.
- Некоторые мобильные браузеры блокируют запуск до пользовательского жеста; первое нажатие одновременно активирует аудиоконтекст. Если Web Audio недоступен, используется HTMLAudioElement, если он есть.
- Функции вывода, вибрации, PWA-инсталляции и фоновое хранение зависят от браузера/платформы. На `file://` Service Worker, офлайн-установка и межвкладочные обновления не работают.
