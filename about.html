Один инструмент.
Несколько задач Windows.

MogLocker — локальное приложение для Windows с разделами мониторинга, диагностики Microsoft Defender, восстановления некоторых пользовательских настроек и браузерной фильтрации. Ниже — подробнее о том, что именно оно делает и чего от него ожидать.

Разделы программы

Что умеет MogLocker

◉

Мониторинг системы

Приложение наблюдает за отдельными признаками, которые могут указывать на окно-блокировщик, включая запущенный процесс regedit.exe и изменения наблюдаемых ключей реестра.

  • Показывает результаты наблюдения в интерфейсе.
  • Отслеживает выбранные изменения системного состояния.
  • Обнаружение — сигнал для проверки, а не автоматическая блокировка.
◇

Диагностика Microsoft Defender

Раздел отображает доступные состояния мониторинга Windows и сведения об исключениях Defender. Для чтения актуального списка исключений Windows запрашивает повышение прав через UAC.

  • Исключения можно просмотреть и выбрать для удаления вручную.
  • Перед удалением Windows снова показывает запрос UAC.
  • Программа не добавляет исключения и не меняет защиту без действия пользователя.
↗

Раздел «Анлок»

Помогает проверить некоторые пользовательские ограничения Windows для Диспетчера задач, Редактора реестра, Командной строки и Панели управления.

  • Перед изменением настроек требуется подтверждение.
  • Удаляются только известные значения политик текущего пользователя (HKCU).
  • Системные политики HKLM приложение не меняет.
⌁

AdBlock для Chrome и Edge

Настольное приложение управляет настройками, а браузерное расширение применяет поддерживаемые правила фильтрации с помощью API браузера.

  • Фильтр-листы, пользовательские правила и список исключений сайтов.
  • Статистика и локальный журнал срабатываний.
  • Поддерживаемое подмножество ABP-фильтров и косметические правила.
Как это устроено

Приложение работает локально

Настольная часть

Главное приложение — Windows Forms на .NET Framework 4.8. Настройки AdBlock и кэш фильтр-листов хранятся локально в профиле пользователя Windows.

Windows 10/11 .NET Framework 4.8 WinForms

Связь с браузером

Для передачи правил между программой и расширением используется Native Messaging API, а фильтрация сетевых запросов опирается на declarativeNetRequest в Manifest V3.

Chrome Microsoft Edge Manifest V3
i
Важно: MogLocker — диагностический прототип, не антивирус.

Он не гарантирует обнаружение угроз, не блокирует процессы и не заменяет Microsoft Defender. Организационные политики Windows могут применяться снова, а обнаруженные изменения сами по себе не указывают на их источник.

Начало работы

Как скачать и подключить

ШАГ 01

Скачайте релиз

Получите MogLocker.exe со страницы релиза. При первом запуске загрузчик устанавливает приложение для текущего пользователя. Если нужен .NET Framework 4.8, появится предложение установить его.

ШАГ 02

Выберите нужный раздел

Откройте программу и изучите мониторинг, Defender или «Анлок». Перед операциями, которым нужны права или изменения настроек, Windows запросит подтверждение.

ШАГ 03

Подключите расширение

В разделе AdBlock нажмите «Подключить браузер», затем откройте страницу расширений Chrome или Edge и загрузите указанную папку browser-extension в режиме разработчика.
